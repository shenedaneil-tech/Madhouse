# MadHouse

A mobile-first, installable PWA prototype for a game-like household management app.

## Current prototype

- Full house view with clickable rooms
- Working Kitchen room
- Interactive Kitchen objects
- Grocery List that saves locally on the device
- PWA manifest and service worker for Home Screen installation

## Next

Add game-quality room artwork, Pantry, Meal Planner, Office, Garage, Bedroom, Bathroom, Living Room, and household cloud sync.
